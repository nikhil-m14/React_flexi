# Flexi React – Challenges 5, 6 & 7

This project is a React + Vite application developed as part of the Flexi React challenges.
It implements **Challenge 5 (Responsive Navigation & Layout)**,  
**Challenge 6 (Comment System)**, and  
**Challenge 7 (Search Functionality)**  
exactly according to the provided design specification PDFs.

---

## 🚀 Tech Stack

- React 18
- Vite
- React Router DOM (v6)
- CSS Modules
- JavaScript (JSX)
